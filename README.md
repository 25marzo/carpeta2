Objetivos del CURSO :
1. Dominar el uso de git como herramienta de gestión de código.
2. Usar CI/CD con github actions
3. Usar github.io como servidor web.
4. Creación y uso de imagenes de docker para su uso en  diferentes modulos
5. Configuración de sistemas de red con docker.
6. Creación de repositorios propios de docker
7. Usar Kubernettes para la orquestación de contendores.

 CONTENIDOS
Creacion de repositorios git
Manejo de repositorios, operaciones básicas Github.
Conceptos avanzados, ramas, pull request,git-flow.
Bases fundamentales de Docker, volúmenes, redes.
Crear de contenedores con Dockerfile.
DockerHub, Docker en Github en repositorios propios.
Docker Compose para crear redes complejas, con varios contenedores.
Servicios de bases de datos y web en contenedores Docker.
Kubernettes con Docker.
